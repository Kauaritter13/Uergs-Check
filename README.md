# Uergs Check

Feito para estudantes da UERGS: marque as matérias que já fez, veja quantos créditos completou e quanto falta para se formar.

Feito com Next.js, TypeScript e Supabase.

## Rodar local

Crie um `.env.local` com `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_ANON_KEY`, e depois:

```bash
pnpm install
pnpm dev
```

As tabelas e os dados iniciais estão em `scripts/`.
